What the tool does with it

  1. Capture headers only

    Per flow: packet sizes, inter-arrival times, direction, burst counts. Payloads stay encrypted.

  2. Learn the attribute

    Gradient-boosted trees under grouped cross-validation, so no prompt appears in both training and test folds.

  3. Test against chance

    Cluster-bootstrap confidence interval on macro-F1 and a permutation test by prompt group.

  4. Give a verdict

    LEAK if the interval's lower end clears chance + 0.05 and p ≤ 0.05. NO LEAK if its upper end stays at or below that line and p > 0.05. Anything else is INCONCLUSIVE.
